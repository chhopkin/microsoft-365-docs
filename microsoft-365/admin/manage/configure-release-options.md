# Configure Standard or Deferred release options for Microsoft 365 Copilot feature updates

As an IT admin, you can now choose to either adopt new, generally available features immediately, or you can choose to delay the rollout of Microsoft 365 Copilot feature updates to your organization by 30 days after general availability.

This article is only about the release options for Copilot features. For information about ______ release options, see [Set up the Standard or Targeted release options for ________](release-options-in-office-365.md).

## Prerequisites

## Standard vs Deferred release options

### Standard release for Copilot updates

Standard release is the default option where you and your users receive the latest Copilot feature updates when they're released broadly to all customers.

### Deferred release for Copilot updates

With Deferred release, you and your users can receive .... You can choose to have individuals or your entire organization receive Copilot updates 30 days after they are generally available.

## Configure Standard or Deferred release options

You can change how your organization receives Microsoft 365 Copilot updates by following these steps. You have to be a global admin in Microsoft 365 to opt in.

[!INCLUDE [global-administrator-note](../../includes/global-administrator-note.md)]

Standard release is the default release option.

1. Sign in to the Microsoft 365 admin center.
1. In the left navigation, expand **Copilot** and select **Settings**.
1. Under the **All Settings** tab, select **Copilot release preferences: General Availability**.
1. Choose either **Standard release** or **Deferred release**.
1. Add any user exceptions.
    - If you select **Standard release** and want a specific user to assign to **Deferred release**, search for the user and select their name.
    - If you select **Deferred release** and want a specific user to assign to **Standard release**, search for the user and select their name.
1. Select **Save**.
